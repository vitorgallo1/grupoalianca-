# Grupo Aliança

Site institucional do Grupo Aliança (groupalianca.com.br).

Site estático: abra `index.html` no navegador ou publique a pasta em qualquer hospedagem (Netlify, Vercel, Hostinger etc.).

- `index.html`: conteúdo
- `styles.css`: estilos e animações
- `script.js`: menu, animações de rolagem, contadores, lista de serviços e formulário (envia pelo WhatsApp)
- `assets/`: logo e fotos
